# Notice

DRAFTJURY is experimental software for BOT Chain. It has not been professionally audited. Review the Solidity source and test with a low-value wallet before production use.

The frontend never asks for a seed phrase or private key. Wallet connection requests account access only; every write action has a separate transaction review.

The reference product was used to understand the public A/B voting workflow. The name, copy, interface, layout, visual system, and implementation in this package are original.
